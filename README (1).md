# Vanitha Velu · Portfolio

Product Designer portfolio: case studies, colleague feedback, an art book and Meenu, the cat assistant.

## Files
- `index.html` is the whole website (styles, scripts, photo, drawings and images are built in).
- `Vanitha_Velu_Resume.pdf` opens when visitors click **Resume**.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

## Publish on GitHub Pages
1. Create a new repository on GitHub, e.g. `portfolio` (Public).
2. Click **Add file → Upload files**, drag in all the files from this folder, then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, set **Source: Deploy from a branch**, **Branch: main**, folder **/ (root)**, then **Save**.
4. After about a minute your site is live at `https://<your-username>.github.io/portfolio/`.

Tip: name the repository `<your-username>.github.io` to get the shorter address `https://<your-username>.github.io/`.

## Notes
- Meenu uses her built-in answers on GitHub Pages (the AI version only runs inside claude.ai).
- To update content later, edit `index.html` and upload it again.
