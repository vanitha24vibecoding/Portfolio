What is Model Explorer?

A workspace for exploring planning data

Fabric Planning helps companies build budgets and forecasts. Model Explorer is where finance and planning users explore the data behind those plans. They arrange it into a table, filter it and compare numbers. With built-in analysis such as Composition, Attribution and Trend, they can select any number to see what drives it, and add the findings to an Intelligence sheet before they plan or report.

Information architecture

Model Explorer is organised into six tool groups: Layout & Totals, Quick Format & Decimals, Comparison, Analysis, Filter & Sort, and Configure Table. Comparison offers five ways to compare measures, including Freeze Columns. Analysis offers eight methods for a selected cell, and each result can be added to an Intelligence sheet.

A challenging UX problem

Comparing two selections meant filtering again and again

A planner wants to compare revenue from Games and Toys with Accessories. They filter to Games and Toys and note the numbers. Then they clear the filter, select Accessories, and try to remember what they saw before.

The problem

Every comparison meant applying and clearing filters over and over.

User need

See values from two different selections side by side.

Business scenario

Revenue from Games and Toys compared with Accessories, region by region.

My approach and design solution

Freeze one selection, keep exploring the other

I introduced Actual and Reference columns, allowing users to freeze one product's values while changing filters in the Actual column. This enables easy side-by-side comparison without repeating the filtering process.

The capability is called Freeze Columns.

Why Actual and Reference?

  • Actual: Shows values based on the current filter selection.
  • Reference: Keeps previously frozen values unchanged for comparison.

I chose these names to make the difference between changing and fixed values clear to users.

Reference

Holds the values from the selection you froze. They stay put while you keep filtering.

Actual

Follows the filters you select right now. Switch the product and these values update.

How Freeze Filter Selection Works

  1. Open the Comparison & Output menu.

  2. Select Freeze Columns.

  3. Click Apply to enable the Actual and Reference columns.

  4. Apply a filter to select the values you want to compare.

  5. Click Freeze Filter Selection to save the current values in the Reference columns.

  6. Change the filters to explore other data.

  7. Actual values update based on the new selection, while Reference values remain unchanged for side-by-side comparison.
